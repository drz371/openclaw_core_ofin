# 个人博客收录网页 - 产品需求文档 (PRD)

## 1. 项目概述

### 1.1 项目背景
创建一个融合个人博客内容与勇者斗恶龙（Dragon Quest）游戏的网页应用。整体设计采用日本知名插画师米山舞（Mai Yoneyama）的独特美学风格。

### 1.2 项目目标
- 构建一个视觉上令人难忘的个人博客展示平台
- 集成一个可玩的勇者斗恶龙风格RPG小游戏
- 以米山舞的美学特征打造独特的视觉体验

## 2. 设计美学方向

### 2.1 米山舞美学特征
- **色彩**: 高对比度、饱和度强烈的配色方案，善用蓝紫渐变与暖色点缀
- **光影**: 戏剧性的明暗对比，强烈的光源效果，逆光与侧光表现
- **构图**: 动态倾斜的视觉角度，打破常规的网格布局
- **字体**: 具有个性的日文/英文字体组合，粗细对比明显
- **装饰**: 几何图形元素、光晕效果、粒子特效、半透明叠加层
- **氛围**: 现代都市感与幻想元素的融合，年轻活力与梦幻交织

### 2.2 色调方案
- 主色调: 深紫蓝 (#1a0a2e)、电光蓝 (#00d4ff)、品红 (#ff006e)
- 辅助色: 琥珀金 (#ffb700)、荧光绿 (#39ff14)
- 背景: 深色渐变配合噪点纹理与光效

## 3. 功能需求

### 3.1 博客模块
- **文章展示区**: 卡片式布局展示博客文章标题、摘要、日期
- **文章分类**: 技术、生活、游戏等分类标签
- **个人介绍**: 侧边栏展示作者头像、简介、社交链接
- **搜索功能**: 快速检索博客内容

### 3.2 勇者斗恶龙游戏模块
- **游戏场景**: 像素风格的RPG冒险场景
- **回合制战斗**: 经典的勇者vs怪物战斗系统
- **角色属性**: HP、MP、攻击力、防御力
- **技能系统**: 攻击、魔法、道具、逃跑
- **怪物图鉴**: 多种怪物类型，不同属性与挑战
- **升级系统**: 战斗后获得经验值，提升等级

### 3.3 导航与交互
- **顶部导航栏**: 博客、游戏、关于 三个主要入口
- **页面切换动画**: 平滑的过渡效果
- **响应式设计**: 适配桌面与移动设备

## 4. 页面结构

### 4.1 首页/博客页
- 顶部导航栏
- 个人简介卡片
- 博客文章列表（网格布局）
- 分类筛选标签
- 搜索框

### 4.2 游戏页
- 游戏画布区域
- 游戏控制面板（战斗选项）
- 角色状态面板（HP/MP/等级）
- 战斗日志区域
- 开始/重新开始按钮

### 4.3 关于页
- 个人介绍
- 技能展示
- 联系方式

## 5. 技术要求

### 5.1 技术栈
- HTML5 + CSS3 + Vanilla JavaScript
- Canvas API 用于游戏渲染
- CSS Grid/Flexbox 用于布局
- CSS动画与过渡效果

### 5.2 性能要求
- 首次加载时间 < 3秒
- 游戏帧率 ≥ 60fps
- 响应式断点: 768px, 1024px, 1440px

### 5.3 浏览器兼容性
- Chrome/Edge (最新2个版本)
- Firefox (最新2个版本)
- Safari (最新2个版本)

## 6. 内容规划

### 6.1 博客文章示例
- 技术类: "WebGL粒子效果实践"
- 游戏类: "勇者斗恶龙系列回顾"
- 设计类: "米山舞的色彩运用解析"
- 生活类: "独立开发者的日常"

### 6.2 游戏内容
- **主角**: 勇者（默认名称，可自定义）
- **怪物**: 史莱姆、巨龙、骷髅战士、暗影法师
- **场景**: 草原、洞穴、城堡
- **技能**: 攻击、火焰魔法、治疗、闪电术
